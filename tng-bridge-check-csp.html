TnG bridge check (production CSP)

Open this page from the TnG app entry point under test. Everything the page learns is printed below, so no debugger is needed. Wait 30 seconds, then press the three copy buttons under the list, one part per message, or screenshot the whole list. Query parameters: clientId, redirectUrl, scopes (comma separated), mode (immediate, afterFinish or both) and extraActions (comma separated read-only actions to call after the auth code answer, default getSystemInfo, or none).

Shape report

The report has three parts, so that each part is small enough to paste on its own. Press Copy TypeScript draft first and send it alone. Then press Copy compact JSON and send it. Then press Copy function sources and send it last. The parts hold member names, types, function arity and function source. They hold no answer value and no URL. The TypeScript is a draft that needs review.
